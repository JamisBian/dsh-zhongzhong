# 中医衷中参西 · DeepSeek Harness 插件（dsh-zhongzhong）

把「中医问诊」做成一个可执行的流程插件：**先问清楚，再辨证，查得到文献才开方**。

本插件是 [dsh-jingfang](https://github.com/JamisBian/dsh-jingfang) 的**完整复刻 + 扩库**：

- **完整保留经方库**：228 首（伤寒六经 99 + 金匮 114 + 杂疗 1 + 手册/后世方 14），数据、问诊、辨证、证据、处方笺、病案导出全部沿用；
- **追加张锡纯《医学衷中参西录》**：医方 33 篇 **174 首**（含 9 首单味方），药物篇 **87 味单方**；
- **统一分析**：经方、张锡纯方、单方走**同一套方证打分、同一道文献门槛、同一张处方笺**，不是两个互不相干的模式；
- 处方剂量按方剂体系分开折算：经方**汉制 1 两 = 3 克**，张锡纯方**清制 1 两 = 30 克**，绝不混用。

**DSH Plugin**（`dsh.bundle.patch` + `dsh.client` 双面插件）· 适用于 DeepSeek Harness
· 仓库：[github.com/JamisBian/dsh-zhongzhong](https://github.com/JamisBian/dsh-zhongzhong)

**适用场景**：感冒发热、咳嗽咽痛、胃胀胃痛、腹泻便秘、失眠多梦、头晕头痛、心悸胸闷、胁肋胀满、口干口苦、小便不利、水肿、关节疼痛、月经不调、痛经、更年期不适；以及张锡纯擅长的**大气下陷（气短不足以息）、脑充血/中风、虚劳劳嗽、吐衄崩漏、消渴、淋浊癃闭、噎膈反胃、瘰疬疮疡、眼科咽喉牙疳**等。

> ⚠️ 本插件是中医学习与辅助工具，输出**不能替代面诊与执业医师处方**。张锡纯原方用量偏重，清制折算后仍须医师按体质、年龄与病情调整；含毒性药的方剂必须在医师指导下使用。

## 一、它和 dsh-jingfang 是什么关系

| 维度 | dsh-jingfang | dsh-zhongzhong |
| --- | --- | --- |
| 经方库 | 228 首 | **228 首，原样保留** |
| 张锡纯方 | 仅作参考层（19 首加减思路） | **174 首可辨证、可开方** |
| 单方（单味药） | 无 | **87 味，可辨证、可开方** |
| 方证引擎 | 一套 | **同一套，扩了清制剂量与单方先验** |
| 证据门槛 | 条文命中 + 吻合度 ≥ 60% | **同一门槛，证据来源多一类「衷中参西录原文/单方」** |
| 问诊 | 4 阶段 | **5 阶段（新增 `special` 衷中参西特征症，按主诉选问）** |
| 方族鉴别 | 四逆/承气/泻心 | **新增升陷汤类、冲脉不固类、淋浊类** |
| 病案 | `~/中医病案` | **同一目录、同一格式，标题改为「中医衷中参西病案」** |

> 「完全复刻」指**功能与数据不缩水**；插件名、技能名、工具前缀改为 `zhongzhong_*`，避免与 dsh-jingfang 同时安装时冲突。

## 二、统一分析：三库同台，一套门禁

方剂库合计 **489 首**：

| 来源 | 数量 | `school` | 证据来源标注 |
| --- | --- | --- | --- |
| 伤寒六经 + 金匮 + 杂疗 + 手册补录方 | 228 | `jingfang` / `shifang` | `仲景原文` / `后世注家方证` / `手册方证` |
| 张锡纯《医学衷中参西录》自拟方 | 174 | `zhongzhong` | `衷中参西录原文` |
| 《医学衷中参西录·药物》单方 | 87 | `zhongzhong` + `bencao: true` | `衷中参西录·单方` |

**统一体现在四处：**

1. **同一个注册表**：`lib/data/index.js` 把三库合并成 `FORMULAS`，按 id 去重，`resolveFormula()` 一律按方名/别名/id 解析；
2. **同一个打分器**：`lib/engine/match.js` 对所有方用同一套「核心方证 55% + 覆盖度 35% + 主症命中 10%」公式；
3. **同一道证据门槛**：`lib/engine/evidence.js` 先查原文/原书主治是否命中患者见症，再要求方证吻合度 ≥ 60%，否则 `weak`/`unsupported`，处方工具直接拒绝；
4. **同一张处方笺**：`lib/engine/prescribe.js` 统一输出组成、折算、煎服法/用法、医嘱、用药警示、免责声明——只在「汉制/清制/单方/外用」上分别标注。

### 统一打分里的三个「先验」

不是所有方在同一条件下完全等权，引擎里有三条公开、可复核的先验：

| 先验 | 作用 | 取值 |
| --- | --- | --- |
| **同经优先** | 病历里某经特征症明确时，同经的仲景方优先 | +0.06 |
| **张氏方深度校正** | 张锡纯方主治文字短、指标少，避免小样本把覆盖度顶满 | 指标 <5 条 −0.04；<7 条 −0.02 |
| **单方降权** | 单味药主治宽泛，不能盖过成方 | 医方里的单味方 −0.02；药物篇单方 −0.12 |

这三条只影响**排序**，不改变「证据不过不给方」的硬门槛；方剂详情与证据卡都会显示依据来源。

## 三、接诊流程（5 阶段）

```
intake（姓名/年龄/性别/主诉/病程/特殊情况）
  → symptoms（寒热/汗/头身/胸腹/饮食）
  → symptoms2（二便/睡眠/咳喘/其他）
  → signs（体温/血压/脉搏/舌象/脉象）
  → special（衷中参西特征症：气机与出血 / 妇科 / 神志与中风 / 消渴与淋浊 / 胸膈五官 / 疮疡皮肤，按主诉选问）
  → differentiate（方证匹配 + 方族鉴别 + 候选确认）
  → evidence（原文/原书主治 + PubMed）
  → prescribe（红旗筛查 → 文献复核 → 患者确认 → 处方笺）
```

- `special` 阶段是**按系统分组的多选题**，与本主诉无关的组直接选「以上都没有」，不必六组全答。
- 任何一步返回 `manual`（当前没有提问界面）时，把返回的 `questions` 交给 `ask_user_question` 代问，答案并回 `case` 后继续。
- `differentiate` 内置置信度门槛：主症命中不足、最高匹配度 < 60%、或首选与次选分差 < 8%（高匹配时 4%）时，**拒绝给出方剂选项**，只返回下一轮鉴别问题。
- 同一方族两首以上进前五时，先问家族鉴别题，再把答案折成「补充症状 + 加减权」。

### 工具一览

| 工具 | 作用 | 关键返回 |
| --- | --- | --- |
| `zhongzhong_consult` | 分阶段问诊（intake / symptoms / symptoms2 / signs / special） | 更新后的 `case`、病历摘要、下一阶段 |
| `zhongzhong_differentiate` | 三库统一方证匹配 + 方族鉴别 + 候选确认 | `decided` / `need_more` / `close_call` |

## 四、两套剂量（最容易被搞混的地方）

| 体系 | 适用 | 折算 | 处方笺标注 |
| --- | --- | --- | --- |
| `han` | 经方（汉制「两/铢/斤」） | **1 两 = 3 克**；1 斤 = 48 克；1 铢 = 0.125 克 | 汉制原量 |
| `qing` | 张锡纯方（清制「两/钱/分/斤/厘」） | **1 两 = 30 克；1 钱 = 3 克；1 分 = 0.3 克；1 斤 = 480 克；1 厘 = 0.03 克** | 张氏原量（清制） |
| `ratio` | 等分/比例丸散 | 不折克数，按原方比例 | 原方比例 |
| `external` | 外用/外治方 | 组成照录，标注「外用，不可内服」 | 外用方 |

例：

```
经方 · 桂枝汤：桂枝 三两（≈9g）       ← 1两=3g
张氏 · 升陷汤：黄芪 六钱（≈18g）       ← 1钱=3g
张氏 · 镇肝熄风汤：怀牛膝 一两（≈30g） ← 1两=30g
```

`zhongzhong_formula` 与 `zhongzhong_prescribe` 都会在卡片里写明用的是哪套折算，**不允许把两套混在一张方里**。

## 六、单方：87 味，来自药物篇

《医学衷中参西录·药物》共 79 个编号条目，其中 6 个条目是「双药合解」（朴硝/硝石、枸杞子/地骨皮、海螵蛸/茜草、茯苓/茯神、三棱/莪术、乳香/没药），1 个是「附子/乌头/天雄」三药合解。拆开并去重后得 **87 味单方**。

每味单方包含：

- 标准药名（`lib/data/herbs.js` 归一，`黄`→黄芪、`萸肉`→山萸肉、`于术`→白术、`大黄芪`→大黄等 OCR 修字）；
- 一句话主治（人工校准，患者能读懂）；
- 3–6 条方证指标，至少 1 条主症（w=3）；
- 原书主用法（煎汤/煮汁/为末/冲服/含化/外敷等）；
- 安全提示（毒性、保护药材、成瘾性等）；
- 原书药物篇全文摘要（`explanation`）。

例：

| 单方 | 一句话主治 | 主症指标 |
| --- | --- | --- |
| 石膏（单味） | 清阳明胃腑实热：壮热、烦渴、汗出、脉洪大 | 发热、口渴喜冷饮、大汗出、脉洪大 |
| 人参（单味） | 大补元气，补脾益肺，生津安神 | 疲乏、气息微弱、食欲差、心悸 |
| 黄芪（单味） | 补气升阳、固表止汗、利水消肿、托疮生肌 | 大气下陷、自汗、水肿、疲乏 |
| 山萸肉（单味） | 收敛元气、固涩滑脱 | 自汗、气息微弱、遗精、尿频 |
| 三七（单味） | 化瘀止血、活血定痛 | 吐血、崩漏、跌打损伤、咳血 |

单方的使用原则：

- **同样要过证据门槛**：证据来源标 `衷中参西录·单方`，不是「随便抓一味药」；
- **同样要患者确认**：处方笺会标「单方（单味药）」；
- **剂量不照搬**：原书常写「随证酌用」「数钱至两许」，工具不给固定克数，必须由医师定量；
- **毒性单方**（马钱子、甘遂、轻粉、铅、朱砂、硫黄、罂粟壳、鸦胆子、藤黄等）强制挂警示；保护药材（穿山甲、犀角、虎骨、羚羊角）提示替代。

## 七、方族鉴别：不再靠猜

同一家族的方症状高度重叠，靠权重永远分不开。`differentiate` 在进入「选方」前，会先检测**前五名里是否有两首以上同族**，有就弹出该族的专属鉴别题：

| 家族 | 成员 | 鉴别点 |
| --- | --- | --- |
| 四逆汤类（经方） | 四逆汤、通脉四逆汤、白通汤、白通加猪胆汁汤…… | 面色、手足冷热、下利 |
| 承气汤类（经方） | 大/小/调胃承气汤、麻子仁丸 | 腹硬拒按、胀满、潮热 |
| 泻心汤类（经方） | 半夏/生姜/甘草泻心汤、黄连汤、旋覆代赭汤 | 心下痞、嗳气、肠鸣、下利 |
| **升陷汤类（张氏）** | 升陷汤、回阳升陷汤、理郁升陷汤、醒脾升陷汤 | 怕冷/气郁/脾虚下陷/单纯大气下陷 |
| **冲脉不固类（张氏）** | 安冲汤、固冲汤、温冲汤 | 暴崩/经期延长/经少怕冷不孕 |
| **淋浊类（张氏）** | 理血汤、膏淋汤、气淋汤、劳淋汤、砂淋丸、寒淋汤 | 血尿/膏浊/遇劳/受寒/砂石/气滞 |

每题都有 **「说不清 / 都不像」** 出口：选了不加权、不补症状，家族鉴别只问一次就退出，退回客观症状继续问。

## 八、文献依据分五类

| 类型 | 来源 | 标注 |
| --- | --- | --- |
| **仲景原文** | 《伤寒论》《金匮要略》条文 | `依据类型：仲景原文` |
| **后世注家方证** | 王付方证讲解的【主治】（用于原本无「论」的方） | `依据类型：后世注家方证` |
| **手册方证** | 黄煌《经方使用手册》（后世方/经验方） | `依据类型：手册方证` |
| **衷中参西录原文** | 张锡纯自拟方的原书主治/方论 | `依据类型：衷中参西录原文` |
| **衷中参西录·单方** | 药物篇单味药的主治与用法 | `依据类型：衷中参西录·单方` |

判定逻辑相同（原文/原书主治命中 + 方证吻合度 ≥ 60%），但依据来源在证据卡与处方笺上都会如实标出。**注家方证、原书主治归纳都不等于仲景原文**，这一点不混着写。

> 张锡纯方的原书主治多用古语（「气短不足以息」「努力呼吸」「脑充血」「噎膈」），患者点选的是规范化症状词。文字没有逐字命中时，证据引擎仍以原书主治为据，但会标注「据原书主治归纳」，并把命中的方证要点列出来——不冒充原文逐字相符。

## 九、安全底线

### 红旗（`prescribe` 直接拒绝并建议急诊）

体温 ≥40℃、血压 ≥180/110 或 ≤85、脉搏 ≥130 或 ≤45、胸痛伴大汗、腹痛拒按伴高热、出血伴头晕/气弱、咳血伴气促、中风伴神志/言语异常、抽搐持续、霍乱吐泻伴肢冷气弱、小便不通伴腹痛、孕妇与 3 岁以下幼儿的任何急性症状。

### 毒性/峻烈药（处方笺自动挂警示）

麻黄、细辛、附子、乌头、天雄、半夏、大黄、朴硝、甘遂、大戟、芫花、马钱子、水蛭、虻虫、朱砂、轻粉、红粉、铅、雄黄、硫黄、硼砂、白矾、皂荚、常山、鸦胆子、罂粟壳、藤黄、胆矾、全蝎、蜈蚣、穿山甲、犀角、虎骨、羚羊角等。

### 十八反 / 十九畏

合方前检查：甘草反甘遂/大戟/海藻/芫花；乌头/附子反半夏/瓜蒌/贝母/白蔹/白及；藜芦反人参/丹参/玄参/细辛/芍药；硫黄畏朴硝；人参畏五灵脂；丁香畏郁金；肉桂畏赤石脂等。命中即拒绝合方。

### 妊娠与基础病

妊娠/备孕：活血、峻下、有毒药一律不用或极慎用；高血压：麻黄、甘草、黄芪、人参需评估；心脏病：麻黄、附子、细辛慎用；糖尿病：甘草、大枣、蜂蜜、糖、粳米需计入；出血/抗凝：活血药叠加有风险；肾功能不全：关木通禁用，细辛、附子、朱砂、轻粉、铅需调整。

## 十、安装

插件包声明了 `dsh.bundle.patch`（宿主工具）与 `dsh.client`（浏览器端卡片），**没有构建步骤**——`lib/` 里就是可直接运行的 ESM 与手写 classic script，装完即用。

### A. 从 GitHub 仓库安装（推荐）

```
https://github.com/JamisBian/dsh-zhongzhong
github:JamisBian/dsh-zhongzhong
JamisBian/dsh-zhongzhong
```

GUI：侧边栏 **Plugins → Add plugin** → 粘贴任一写法 → **Install** → 在列表里对该插件选 **Enable now** → **重启应用**。

命令行（`DSH_HOME` 指向你实际在用的 profile 根）：

```bash
# Linux 原生 profile
dsh plugin --profile web add github:JamisBian/dsh-zhongzhong

# 桌面版（Windows 构建跑在 Wine 里，profile 在 Wine 的家目录）
DSH_HOME="$HOME/.wine/drive_c/users/$USER/.dsh" \
  dsh plugin --profile desktop add github:JamisBian/dsh-zhongzhong
```

装完 `dsh-zhongzhong` 会自动追加进 `dsh.profile.bundles`；**重启应用**后生效（profile 只在启动时组合）。

### B. 从本地路径安装（改代码时用）

```bash
# GUI：Plugins → Add plugin → 选仓库根目录（含 package.json 那一层）
dsh plugin --profile web add /path/to/dsh-zhongzhong
```

- 改 `lib/client.js`（卡片）：重载窗口即可
- 改 `lib/tools.js`、`lib/engine/*`、`lib/data/*`（宿主侧）：**必须完全退出并重启应用**

### C. 确认装好了

```bash
dsh --profile web --dump-config | grep dsh-zhongzhong   # 应能看到 zhongzhong 这一行
```

重启后输入框敲 `/`，菜单里应出现 **zhongzhong**；或直接说「我这两天头痛怕冷」「我气短、吸气费劲」。

## 十一、用起来是什么样

### 例 1：大气下陷 → 升陷汤

```
你：我气短，吸气特别费劲，老觉得气不够用
AI：（zhongzhong_consult intake）
    ↳ 卡片：称呼 / 年龄 / 性别 / 主诉 / 病程 / 特殊情况
你：王先生，52，男，气短、吸气费劲，1–4 周
AI：（symptoms → symptoms2 → signs → special）
    ↳ 胸膈满闷、自汗、短气、疲乏；舌淡白、脉沉微弱
    ↳ special 勾选：胸中大气下陷（气短不足以息）、努力呼吸
AI：（zhongzhong_differentiate）
    ↳ 家族鉴别：就是气短、吸气费劲，没有明显怕冷，也不觉得郁闷 → 升陷汤
    ↳ 候选：升陷汤（推荐，96%）/ 生脉散 88% / 补中益气汤 76%
你：升陷汤
AI：（zhongzhong_evidence）
    ↳ 结论：有文献支撑（96%）
      依据类型：衷中参西录原文
      《医学衷中参西录·医方(三)·治大气下陷方》升陷汤主治：
      「治胸中大气下陷，气短不足以息。或努力呼吸，有似乎喘……」
      PubMed：Shengxian Tang 相关研究 N 篇
AI：（zhongzhong_prescribe）
    ↳ 卡片：确认开方 / 先看文献依据 / 换一个方 / 暂不开方
你：确认开方
    ↳ 处方笺：黄芪 六钱(≈18g) 知母 三钱(≈9g) 柴胡 一钱五分(≈4.5g)
      桔梗 一钱五分(≈4.5g) 升麻 一钱(≈3g)
      张氏原量（清制）：1 两 = 30 克、1 钱 = 3 克……
      煎服法、医嘱、用药警示、免责声明
```

### 例 2：脑充血/中风先兆 → 镇肝熄风汤

```
你：我头晕胀痛、耳鸣，右边手脚有点不听使唤，血压也高
AI：（问诊 + special：脑充血/头目胀痛、半身不遂、口眼歪斜、脉弦长有力）
    ↳ zhongzhong_differentiate：镇肝熄风汤（94%）
    ↳ 证据：衷中参西录原文命中；处方笺：怀牛膝 一两(≈30g)、生赭石 一两(≈30g)……
    ↳ 警示：赭石先煎、孕妇慎用；出现意识改变立即急诊
```

### 例 3：单方石膏

```
你：我高烧、特别渴、出大汗
AI：（问诊：发热、口渴喜冷饮、大汗出、脉洪大）
    ↳ 统一排序：白虎汤 / 白虎加人参汤在前，石膏（单味）也在候选（有先验降权）
    ↳ 若患者明确只要单方，或成方都不合适：zhongzhong_evidence(石膏（单味）)
      结论：有文献支撑；依据类型：衷中参西录·单方
    ↳ 处方笺：石膏（单味） 随证酌用（单味）
      单方（单味药），剂量须由医师确定；热退即止
```

### 例 4：患者质疑

```
你：我觉得应该清热，不该用桂枝
AI：（zhongzhong_discuss）
    ↳ 追问：这个看法来自哪里？最担心哪一点？
你：网上看的，怕药太热
    ↳ 我的判断不变：桂枝汤
      一、您身上的方证要点：恶风、自汗、头痛、脉浮弱
      二、原文依据：第12条、第13条
      三、现代文献：PMID …
      我理解您的顾虑：用量按 1 两=3g 折算，附煎法与禁忌…
      什么情况下我会改方：大汗、脉转微弱、服药后加重…
```

如果患者说「我怀孕两个月了」：工具会立刻判定 `revise`，列出方中妊娠禁忌药，明确认错并换方。

## 十三、数据来源与处理

| 文档 | 怎么用的 |
| --- | --- |
| 《医学衷中参西录》原文 | `data/医学衷中参西录.txt`（张锡纯，清，1909；公共领域）。按「一、医方(一)…(三十三)」「二、药物」分节，逐方解析方名、主治（属性）、组成、剂量、用法、方论 |
| 人工校准 | `lib/data/zhongzhong-calibrated.js`（174 首方）、`lib/data/danfang-calibrated.js`（87 味单方）：逐方/逐药给出主症 w=3、兼症 w=2、或然 w=1 |
| 药名归一 | `lib/data/herbs.js`：把「生杭芍/萸肉/于术/大黄芪/牛黄芪/黄芪柏/浓朴/栝蒌/萆/芎」等 OCR 或古写统一成标准名，并保留炮制前缀 |
| 剂量解析 | 支持「一两、钱半、二两半、一钱五分、各二钱、八十一枚、不拘多少、等分」等写法；替代说明（「如无鲜者可用干者二钱代之」）不会被误算进本方 |
| 派生方 | 原书用「即前方加…」写的方（三鲜饮、荡痰加甘遂汤、薯蓣鸡子黄粥、滋阴宣解汤、滋阴清燥汤）从底方推导组成，并标注 `derivedFrom` |
| 缺失/异文 | 清降汤原文在传本中残缺，按《中医大辞典》所引《医学衷中参西录》补组成与主治；古方马乳饮按原书主方（马乳）校正，后附「金银花…」方不混入 |
| 经方库 | 完整沿用 dsh-jingfang 的伤寒/金匮/手册/注家数据与校准，不改动 |

### 已知边界

- 清制折算采用「1 两 = 30 克」的临床通行换算；若按库平制 1 两 ≈ 37.3 克，数值会更大。插件明确标「张氏原量」，并提示不可照搬。
- 张锡纯方主治文字短、部分方只有 1–3 个特征症；引擎用「深度校正 + 原书主治归纳」处理，仍可能出现「需要继续鉴别」而不是直接定方——这符合「宁可多问，不可早断」。
- 药物篇单方的主治是人工从原书本草/医案中提炼的**一句话归纳**，不是原书逐字；原书全文摘要保留在 `explanation` 里可查。
- PubMed 只覆盖英文文献；张锡纯方多数没有稳定英文名，`modern.terms` 只为常用方配置，未配置的方会如实显示「本方未配置英文/日文检索词」。
- 外用方（姜胶膏、通结用葱白熨法、磨翳水/散、明目蓬硝水、清脑黄连膏、消瘰膏、化腐生肌散、牙疳散）只能外用，处方笺会强制标注「不可内服」。
- 辨证是规则引擎，不是大模型自由发挥；规则覆盖不到的证型会返回 `insufficient`，此时应线下就诊。
- 本插件不构成医疗建议；处方必须由执业中医师面诊后开具。
